# CAR IN 시연 가이드

심사위원이 Pleos Connect 에뮬레이터(또는 Android 기기)에서 그대로 따라 할 수 있는 단계별 안내입니다. 소요 시간 약 4분.
"데모"라고 표시된 부분만 SDK 대신 앱 내부 선택을 사용하며, 나머지는 실제 코드 경로입니다.

## 0. 준비

| 항목 | 값 |
|---|---|
| APK | `apk/CARIN_CAR_IN_release.apk` |
| 설치 | `adb install -r apk/CARIN_CAR_IN_release.apk` |
| 실행 | 런처의 **CAR IN** 아이콘 또는 `adb shell am start -n com.carin.noraebang/.MainActivity` |
| 권장 환경 | Pleos Connect Emulator v2.1.0 (Android 14, 2560×1440), 주차(P) 상태 |

첫 화면 구성 (위에서 아래로)
- **헤더**: 왼쪽 주행 상태 칩(`● 주행 상태 확인 전` → 기능 사용 시 `● 주차 중 · 모든 기능 사용 가능`), 가운데 **CAR IN** 로고, 오른쪽 목적지 칩(`목적지 없음` / `[DEMO] 강릉역` / `(SDK) …`)
- **탭**: ▶ 카인 플레이리스트 · 🎙 카인 노래방 · ✧ 카인 추억 (선택된 탭이 코랄색으로 강조)
- **히어로 카드**: "그 길을 다시 달릴 때, 그날의 노래가 흘러나옵니다." + **내비 목적지 조회 / 데모 목적지** 버튼 + 오른쪽 장식 경로선
- **아래 두 패널**: 왼쪽 **카인 플레이리스트**(곡 3개), 오른쪽 **MEMORY ROUTE**(`실제 내비 목적지 (SDK)` / `데모 목적지` 상태, 목적지·추억 버튼, 접힌 "개발 정보")
- **미니 플레이어**(하단 고정): 썸네일 · 곡 제목 · 진행 바 · ⏮ ▶ ⏭ · 목록

> `실제 내비 목적지 (SDK): 설정된 목적지 없음 · 조회 성공` 은 NaviHelper SDK가 실제로 연결·조회되었다는 뜻입니다. 내비 앱에 목적지가 있으면 그 이름이 표시되고 3단계를 건너뛰어도 자동 매칭됩니다.

> 사진이 없는 곳(히어로 카드·노래방·추억 카드)은 노을 그라디언트가 기본 배경입니다. 팀이 `app/src/main/assets/backgrounds/`에 예시 이미지를 넣으면 그 이미지로 바뀝니다.

## 1. 음악 재생 (10초) — 카인 플레이리스트

1. 미니 플레이어의 코랄색 **▶** → 아이콘이 **⏸**로 바뀌고, 플레이리스트 패널 칩이 `♪ 재생 중`, 진행 바가 차오름
2. **⏭ / ⏮** 로 곡 전환 → 곡 목록의 강조(`재생 중 ♫`)가 함께 이동
3. 곡 목록의 행을 누르면 그 곡이 바로 재생됨

## 2. 추억 등록 (40초)

**방법 A — 직접 등록**: MEMORY ROUTE 패널의 **+ 추억 등록** → (주차 확인 후 열림) 장소 `강릉`, 제목 `우리의 강릉 여행`, 📅 날짜, 노래는 알약 버튼에서 **두 번째 노래** → **저장** → 토스트 `추억이 저장되었습니다 · 강릉 / 두 번째 노래`

**방법 B — 데모 데이터**: **데모 데이터 만들기** → `데모 기록 생성: 강릉 · 첫 번째 노래` (이미 있으면 중복 생성 안 됨, `데모 데이터` 칩으로 구분)

## 3. 강릉 목적지 선택 (20초)

- 실제 내비: 내비 앱에서 강릉(예: 강릉역)을 목적지로 설정 후 **내비 목적지 조회** (변경 이벤트가 오면 자동 반영)
- 데모: 히어로 카드의 **데모 목적지** (또는 패널의 **데모 목적지 선택**) → 창에서 **강릉역** → 헤더 칩·패널에 `[DEMO] 강릉역`

## 4. 추억 발견 (즉시)

플레이리스트 탭의 히어로 카드가 바뀌며 살짝 강조됩니다(다른 탭에 있었으면 플레이리스트 탭으로 이동).

- `[DEMO] 강릉역` 칩
- **"지난번 이 길에서 들었던 노래가 있어요. 다시 들어보시겠어요?"**
- 📍 추억 제목 · 날짜, ♫ 그날의 노래
- **▶ 재생하기 / 나중에**, 오른쪽 경로선 끝에 `강릉`
- 같은 장소 추억이 여러 개면 카드 아래 점으로 넘겨 봄 (최근 여행 우선)

**나중에**를 누르면 문구가 "강릉역에서의 추억 N개"로 접히고 **그날의 노래 / 추억 보기** 버튼이 남습니다.

## 5. 추억 음악 재생 (즉시)

**▶ 재생하기** → 미니 플레이어가 그 곡으로 이동해 재생됩니다. 기존 ExoPlayer가 재생하므로 일시정지·곡 전환도 그대로 동작합니다.

## 6. 카인 추억 조회 (30초)

1. **✧ 카인 추억** 탭 → 제목 옆에 개수 칩, 오른쪽에 **데모 데이터 / + 추억 등록**
2. 사진 카드 그리드: 사진(없으면 노을 그라디언트) 위 제목, 📅 날짜 · 📍 장소 · ♫ 노래, **▶ 그날의 노래 / 자세히**
3. **자세히**(또는 카드 터치) → 상세 창: 왼쪽 사진 + 경로선, 오른쪽 날짜·장소·노래·구분(실제 기록/데모 데이터)·등록 시각
   - 버튼 **삭제 · 사진 연결 · 노래방 · ▶ 그날의 노래**
4. **삭제** → 확인 창 → 목록·히어로 카드 즉시 갱신 (주행 중에는 차단)
5. 기록이 없으면 "아직 저장된 추억이 없어요"와 **첫 추억 등록하기** 버튼

## 7. 카인 노래방 최소 체험 (60초)

1. **🎙 카인 노래방** 탭 → 주차 상태 확인 후 전체 화면 진입 (탭 강조가 노래방으로 이동)
   - 상단: 로고 · "카인 노래방" · 오른쪽 위 `정적 데모 가사 · 팀 자체 제작 · 음악과 동기화되지 않음` 칩 · ✕
   - 가운데: 곡 제목, **현재 가사 줄(코랄, 크게)** 과 다음 줄(흰색), `1 / 8 · 가사를 누르면 다음 줄, 왼쪽을 누르면 이전 줄`
   - 하단 유리 바: 경과/전체 시간 진행 바, **사진 선택 · ⏮ ▶ ⏭ · 기본 배경**
2. 가사 영역을 누르면 다음 줄, 왼쪽 1/3을 누르면 이전 줄 (자동 진행 없음 — 동기화가 없다는 표기와 일치)
3. **▶ / ⏮ / ⏭** — 미니 플레이어와 같은 상태를 공유 (곡이 바뀌면 제목·가사도 첫 줄부터 바뀜)
4. **사진 선택** → 시스템 포토 피커 → 사진 선택 → 배경에 표시, `배경: 내 사진`
   - 사진이 없거나 열 수 없으면 기본 배경 유지
   - 배경 순서: 지금 곡과 연결된 추억 사진 → 노래방에서 고른 사진 → 기본 노래방 이미지. 곡을 넘기면 배경도 그 곡의 추억 사진으로 바뀝니다
5. **기본 배경** 으로 되돌리기
6. **✕** 또는 뒤로가기 → 메인으로 복귀 (재생 상태 유지)
7. (연계) 카인 추억 상세의 **사진 연결** 로 사진을 붙인 뒤 **노래방** 을 누르면 그 추억의 노래 + 사진 배경으로 노래방이 열립니다.

> 에뮬레이터에 사진이 없다면: `adb shell content insert --user 10 --uri content://media/external/images/media --bind _display_name:s:trip.png --bind mime_type:s:image/png --bind relative_path:s:Pictures/` 로 행을 만든 뒤 `adb shell "content write --user 10 --uri content://media/external/images/media/<id> < /data/local/tmp/trip.png"` 로 바이트를 넣으면 포토 피커에 나타납니다. (`adb push` 로 `/data/local/tmp/`에 먼저 올려 두세요.)

## 8. 추가 확인 포인트

| 시나리오 | 조작 | 기대 결과 |
|---|---|---|
| 기록 없는 목적지 | 데모 목적지 → **부산역** | 히어로 카드 `'부산역'과(와) 연결된 추억이 없어요.` + **추억 등록 / 다른 목적지** |
| 중복 제안 방지 | 같은 목적지 재선택 | 카드는 갱신되지만 탭 이동·강조는 다시 하지 않음 |
| 데모 목적지 해제 | 데모 목적지 창 → **데모 목적지 해제** | 헤더 칩 `목적지 없음`, 히어로 카드 기본 문구 |
| 영속성 | `adb shell am force-stop com.carin.noraebang` 후 재실행 | 추억·노래방 배경 유지 |
| 주행 안전 | 주행 중(CarUxRestrictions DO 필요) 상태에서 추억 등록/삭제/노래방/사진 | 토스트로 차단, 헤더 칩 `● 주행 중 · 음악 재생만 가능`, 음악 재생은 계속 |
| 개발 정보 | MEMORY ROUTE 패널 하단 **개발 정보 · Vehicle SDK** | 펼치면 조수석 착좌 상태 조회(Vehicle SDK) |

## 9. 자주 묻는 질문

- **실제 내비 목적지 vs 데모 목적지?** 첫 줄은 NaviHelper `getDestinationInfo()` 결과, 둘째 줄은 앱 내부 선택. SDK 목적지가 있으면 항상 우선하고 데모는 자동 해제됩니다. 화면에는 항상 `(SDK)` / `[DEMO]`로 구분해 표시합니다.
- **"강릉"이 "강릉역"에 매칭되는 이유?** 이름/주소를 토큰으로 나누고 행정 접미사(역·시·군·광역시…)를 떼어 완전 일치 비교합니다. "산"은 "부산"에 걸리지 않습니다.
- **카드의 경로선은 실제 이동 경로인가요?** 아니요. 장식용 그림이며 도착 라벨에만 추억 장소를 씁니다. GPS 경로·거리·시간 기록은 2차 범위입니다.
- **노래방 가사는 실제 가사인가요?** 아니요. 팀이 직접 쓴 정적 데모 문구이며 음악과 동기화되지 않습니다. 실제 가사·MR·마이크는 2차 범위입니다.
- **주차 판정 기준?** AAOS `CarUxRestrictionsManager.isRequiresDistractionOptimization()`. 속도 0만으로 판단하지 않고, 확인 불가 시에도 제한합니다.
