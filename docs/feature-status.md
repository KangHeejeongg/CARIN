### 확인 과제: 카인을 켜지 않아도 목적지로 추억 노래 제안 (2026-11-15 기록)

현재 상태: NaviHelper `onDestinationChanged` 리스너는 `MainActivity`에 묶여 있어 카인 화면이 떠 있을 때만 자동 제안한다(`onDestroy`에서 해제). 에뮬레이터에서는 실제 내비 목적지를 설정할 수 없어 자동 경로를 끝까지 검증하지 못했다.

| # | 확인할 것 | 방법 · 판단 기준 |
|---|---|---|
| 1 | 실차/실내비에서 목적지 입력 → 카인 자동 제안이 실제로 오는지 | 카인을 띄운 채 내비 목적지 설정, `logcat -s CARIN_NAVI`로 `onDestinationChanged`·조회 결과 확인 |
| 2 | 카인 화면이 꺼져 있어도 목적지 변경을 받을 수 있는지 | 리스너를 `CarinPlaybackService`로 옮기는 안. 재생하지 않을 때 서비스를 유지해도 되는지, 부팅 후 자동 시작이 허용되는지 Pleos에 문의 |
| 3 | 다른 앱 사용 중 제안을 어떻게 알릴지 | Pleos 심사 가이드: 미디어 앱 헤드업 알림 금지, 운전과 무관한 알림 불허 → 팝업은 거절 위험. 대안: 미디어 세션의 다음 곡·부제를 "그날의 노래"로 준비(팝업 없음) |
| 4 | Gleo AI가 먼저 음성으로 "추억 노래를 들려드릴까요?"라고 제안할 수 있는지 | Gleo Interface 문서(`/docs/pleos-only/app-integration-guide/guide/core-concepts`) 미확인. 앱이 Gleo 발화를 시작시킬 수 있는지, 스키마 등록 방식 확인 |
| 5 | Gleo 음성 검색으로 카인 곡 재생이 되는지 | Media3 `onSearch`는 구현됨. 실차에서 "카인에서 바다 빛 드라이브 틀어 줘" 확인 |

진행 순서 제안: 1·4번 확인과 Pleos 문의 → 2·3번(서비스 리스너 + 미디어 세션 제안) `phase2` 브랜치 구현 → PT에서는 Gleo 음성 제안을 확장 시나리오로 설명.
