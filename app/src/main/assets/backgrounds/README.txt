CAR IN 기본 배경 이미지 슬롯

이 폴더에 아래 이름으로 이미지를 넣으면 다시 빌드할 때 앱에 포함됩니다.
(확장자 .jpg / .jpeg / .png / .webp 모두 가능, 긴 변 1600px 이하 권장)

  hero.jpg     카인 플레이리스트 탭의 큰 추억 카드 + 하단 미니 플레이어 썸네일
  karaoke.jpg  카인 노래방 기본 배경 (사용자가 사진을 고르지 않았을 때)
  memory.jpg   카인 추억 카드 / 상세 화면 기본 사진 (추억에 사진을 연결하지 않았을 때)
  default.jpg  위 파일이 없을 때 모든 슬롯에 공통으로 쓰는 예비 이미지

우선순위: 사용자가 고른 사진 > 슬롯 이미지 > default 이미지 > 노을 그라디언트(코드)
노래방은 그 앞에 '지금 곡과 연결된 추억의 사진'이 먼저 쓰입니다
(추억 상세 > 사진 연결로 붙인 사진).
